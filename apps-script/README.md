# 공용 데이터 설정 (구글 시트 + Apps Script)

모든 담당자가 같은 상품·발행본·열 설정을 함께 수정하도록, 구글 시트를 데이터베이스처럼 씁니다.
한 번만 설정하면 됩니다. (약 5분)

## 1. 시트와 스크립트 만들기

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만듭니다. (이름 예: `팜넷 카탈로그 DB`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣은 뒤 저장합니다.
4. 상단의 함수 선택 칸에서 **`authorize`**를 고르고 **실행**합니다. 권한 요청이 뜨면 허용합니다.
   (스프레드시트와 드라이브 접근 권한입니다. "확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르세요.)

## 2. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누르고 유형을 **웹 앱**으로 고릅니다.
2. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 설정하고 **배포**합니다.
3. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 앱에 연결

`dist/config.js`의 따옴표 안에 URL을 붙여넣고 커밋·푸시합니다.

```js
window.FARMNET_API = "https://script.google.com/macros/s/…/exec";
```

처음 접속하는 사람이 열면, 시트가 비어 있을 때 기본 상품 목록이 자동으로 채워집니다.

## 동작 방식

| 항목 | 저장 위치 |
|---|---|
| 상품, 상태, 상품 순서 | 시트 `products` (한 줄 = 상품 1개) |
| 발행된 월호와 발행 당시 상품 | 시트 `issues`, `issue_products` |
| 열 순서, 열 너비 | 시트 `settings` (모두에게 공통) |
| 새로 올린 상품 사진 | 드라이브 폴더 `팜넷 카탈로그 상품사진` (시트에는 주소만 저장) |

- **동시 수정**: 바뀐 항목만 보내므로 서로 다른 상품이나 다른 칸을 동시에 고쳐도 덮어쓰지 않습니다. 같은 칸을 동시에 고치면 나중에 저장한 값이 남습니다.
- **반영 속도**: 다른 사람의 변경은 약 6~10초 안에 화면에 나타납니다. 입력 중이거나 팝업이 열려 있으면 끝난 뒤에 갱신됩니다.
- 화면 위쪽에 `저장 중… / ✓ 공유됨 / ⚠ 저장 실패` 상태가 표시됩니다. 실패하면 5초마다 자동으로 다시 시도합니다.
- 시트를 직접 고쳐도 되지만 `uid`, `order` 열은 건드리지 마세요.

## 접근 제어 (선택)

기본은 링크를 아는 누구나 수정할 수 있습니다. 웹앱 주소가 공개 저장소에 들어 있으므로, 유출을 막고 싶다면
`Code.gs` 맨 위의 `EDIT_CODE`에 코드를 적고 **배포 → 배포 관리 → 새 버전**으로 다시 배포하세요.
그러면 처음 저장할 때 코드를 입력한 사람만 수정할 수 있습니다. (열람과 외부 카탈로그는 계속 자유)

## 코드를 고쳤을 때

`Code.gs`를 수정하면 **배포 → 배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다. (URL은 그대로입니다.)

## 한계

- 요청마다 1~2초 걸리고, 구글의 하루 사용량 제한이 있어 수십 명 규모까지 적합합니다.
- 실시간 동기화가 아니라 주기적 확인 방식입니다.
